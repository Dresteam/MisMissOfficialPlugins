# 求签插件（qiuqian）

发送 **求签**（别名：**抽签**）随机抽取一支诸葛神算签文，回复签号、吉凶、签诗与解签。

## 效果示例

```
@TexasTheDrest
求签结果：您抽到的是第三百三十四签【上签】

签诗：自从持守定，功在众人先，别有非常喜，随龙到九天。

解签：一人做任何事，具有恒心、毅力，则其成功机会较大。

♱⋰ ⋱✮⋰ ⋱♱⋰ ⋱✮⋰ ⋱♱⋰ ⋱✮⋰
```

## 工作方式：每次发送实时解签

- 抽中**已缓存**的签号（打包的种子签文 + 历史抽签缓存）→ 立即回复；
- 抽中**未缓存**的签号 → 实时从吉运堂（[www.jiyuntang.com](https://www.jiyuntang.com/zhuge/)）
  抓取该签页面解签，并写入插件数据目录缓存，之后同号秒回；
- 抓取失败时 → 从已有缓存随机抽取兜底回复；本地无任何签文时才提示失败。

因此插件**无需一次性预抓全部 384 签**——数据随使用自然积累，断网也能靠缓存兜底。
`lots.json` 为打包的种子签文（预抓取的一部分）；如需补齐全部 384 签，
可在插件目录运行 `py update_lots.py`（支持断点续抓）。

## 配置项

全部配置项可在 Web 控制台修改，常用项：

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `cmd_qiuqian` | `求签` | 指令名 |
| `cmd_qiuqian_aliases` | `["抽签"]` | 指令别名（精确匹配） |
| `enabled_rooms` | `[]` | 启用直播间 ID 列表（空=全部） |
| `live_fetch` | `true` | 抽中未缓存签号时实时抓取解签 |
| `fetch_fail_text` | `求签失败啦，稍后再来试试吧~` | 无可用签文时的提示 |
| `result_line` | `求签结果：您抽到的是第{n}签【{f}】` | 结果行模板 |
| `poem_line` | `签诗：{p}` | 签诗行模板 |
| `intpn_line` | `解签：{i}` | 解签行模板 |
| `show_intpn_2` | `false` | 是否追加显示解签二 |
| `separator` | `♱⋰ ⋱✮⋰ ⋱♱⋰ ⋱✮⋰ ⋱♱⋰ ⋱✮⋰` | 底部装饰线 |

## 签文数据

来源：吉运堂 [www.jiyuntang.com](https://www.jiyuntang.com/zhuge/)。
