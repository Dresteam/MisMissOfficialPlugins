# 星座运势插件（zodiac）

发送 **星座 天蝎座**（或 **星座 天蝎**，别名 **运势 天蝎**）查看当日运势。

## 效果示例

```
@TexasTheDrest
　　　♏️天蝎座运势♏️

感情：73%
健康：70%　幸运颜色：西瓜红
财运：70%　幸运数字：70
工作：89%　速配星座：天秤座
综合：76%

┈┈┈┈┈今日运势┈┈┈┈┈
　　今日整体运势稳中有变，变化中蕴含着成长的机会。……
```

## 数据源与工作方式

- 数据来源：[小小API 星座运势接口](https://xxapi.cn/doc/horoscope)
  `GET https://v2.xxapi.cn/api/horoscope?type=scorpio&time=today`，免费、无需密钥；
- 查询结果按「日期+星座」缓存到插件数据目录——**同一天同一星座只请求一次 API**
  （对应原版按天缓存的行为），断网时当天已查过的星座仍可回复；
- API 失败时自动回退**本地生成**好运运势（可配置 `fallback_local` 关闭）；
- 接口返回文本中夹带的推广水印（如「星h座h屋」）已自动清洗；
- `time_type` 支持 `today` / `week` / `month` / `year`，分隔线随类型自动变化。

## 配置项

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `cmd_zodiac` | `星座` | 指令名 |
| `cmd_zodiac_aliases` | `["运势"]` | 指令别名 |
| `enabled_rooms` | `[]` | 启用直播间 ID 列表（空=全部） |
| `time_type` | `today` | 运势类型：today/week/month/year |
| `fallback_local` | `true` | API 失败时回退本地生成 |
| `show_todo` | `false` | 是否显示接口的宜/忌 |
| `separator` | `┈┈┈┈┈{t}┈┈┈┈┈` | 分隔线（{t}=运势类型） |
| 各行模板 | 见 `_conf_schema.json` | `{v}`数值、`{c}`颜色、`{n}`数字、`{f}`速配星座 |

## 支持输入

`星座 天蝎` / `星座 天蝎座` / `运势 天蝎座`，共 12 星座。
