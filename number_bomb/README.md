# 数字炸弹插件（number_bomb）

数字炸弹小游戏

## 玩法

| 指令 | 谁可以 | 说明 |
|------|--------|------|
| `数字炸弹 [最大值]` | 授权用户 | 初始化/重置游戏，**清空玩家列表**并重新随机炸弹（默认 100，最小 10；游戏进行中时仅提示，不打断对局） |
| `加入` / `+` | 观众 | 参与游戏（含上局不在名单的新玩家） |
| `退出` / `-` | 观众 | 退出游戏（仅准备阶段） |
| `开始` | 授权用户 | 随机打乱顺序并开赛（需 ≥2 人） |
| 数字 | 当前玩家 | 猜炸弹：猜中结束；未猜中缩小区间并轮转 |
| `跳过` | 授权用户 | 跳过当前玩家 |
| `结束` | 授权用户 | 进行中：强制结束（自动续局）；准备中：强制停止（清空玩家、回到未初始化，无法再加入） |

## 自动续局（保留玩家列表）

**一轮游戏结束后（猜中或强制结束）自动进入下一轮准备，并保留
上局玩家列表**：

- 上局玩家直接 `开始` 即可再开一局（顺序每次随机）；
- 上局不在名单的新玩家可随时 `+` 加入；
- 需要清空列表重新开局时，发送 `数字炸弹` 指令；
- 游戏进行中发送 `数字炸弹` 只会提示「游戏正在进行中哦~」。

## 计分榜

- **记账规则**：未踩中炸弹（幸存）+1 分，踩中炸弹不加分；管理员「跳过」不计分；
- **输出时机**：仅在**每局结束**（有人踩雷）时输出，其余时间不输出、也不提供查询指令；
- **不持久化**：分数存在内存中，插件重启即清空；
- **重置**：发送 `数字炸弹` 初始化游戏时清零计分榜（跨局累计，直到重新初始化）。

输出示例（纯文本样式）：

```

★--☁✨☁ 积分榜☁✨☁--★

❥•2 @小明 1分
❥•3 @小红 1分
[数字炸弹] 新的一局已就绪，发送 [加入] 或 [+] 即可参与，上局玩家可直接发送 [开始] 再战～
```

Web 面板的「计分榜」列也会实时显示当前分数（如 `小刚 2分、小明 1分`）。

## 文案特性

文案围绕规则「**猜中炸弹的人输**」设计——猜错是幸存，猜中才是出局：

- **猜错** → `😮💨 @小明 猜的 34 不是炸弹，安全幸存～`
- **管理员跳过** → `⏭️ 已跳过 @小明`（与猜错区分）
- **踩中炸弹** → 出局，显示炸弹数字与踩雷者：

  ```
  💥 BOOM！@小明 踩中了炸弹 50，当场出局～
  💥 轰隆——@小明 撞上了炸弹 50，光荣牺牲！
  💥 BOOM！炸弹 50 被 @小明 引爆了，其他玩家成功苟活～
  ```

- 区间**只剩 3/2/1 个数**时触发**气氛文案**（每档一个文案池，随机取一条）：

  | 剩余 | 示例文案 |
  |------|---------|
  | 3 个 | 🍿 事情开始变得有趣起来了……{a}、{b}、{c}，中奖率三分之一哦 |
  | 2 个 | 🎉 欢乐二选一！{a} 还是 {b}？一半是天堂，一半是炸弹～ |
  | 1 个 | 😏 就剩 {a} 一个数了，下一个张口的人必踩雷，要不先写好遗言？ |

- 开局播报带规则提示（`msg_start_rule`，可留空关闭）：
  `（轮流猜数，踩中炸弹的人出局哦～）`

每档文案池在配置中为数组，可自由增删（写成单个字符串也兼容）。
全部文案可在 Web 控制台修改。

## 与 Java 版的不同

- **自动续局**——结束后自动初始化下一轮并保留玩家列表，
  `数字炸弹` 指令变为重置/清空玩家列表；
- **账户级单局**——多账户由插件实例隔离（Java 版为单房间）；
- 授权用户 = `op_users` 列表中的用户 +（`allow_admins` 开启时）直播间管理员；
- 提供 Web 前端查看对局状态与远程操作。

## 配置项

全部指令名与提示文案可在 Web 控制台修改，常用项：

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `op_users` | `[]` | 授权用户 ID 列表 |
| `allow_admins` | `true` | 直播间管理员视为授权用户 |
| `default_max_number` | `100` | 默认最大数字 |
| `min_max_number` | `10` | 最小允许范围 |

## Web UI

插件自带声明式前端（`_ui_schema.json`），在 Web 控制台插件页可：

- **对局概览**：进行中/准备中的局数、总参与玩家数；
- **当前对局表**：本账户唯一一局的状态徽章（未初始化/准备中/进行中）、
  当前范围、人数、玩家列表（当前玩家带标记）、当前玩家；
- **行内操作**（按状态自动显示可用按钮）：
  `初始化`（清空玩家重新开局）/ `开始游戏` / `跳过` /
  `结束游戏`（进行中）/ `停止游戏`（准备中），
  操作会同步向直播间广播对应消息；
- **自定义范围初始化表单**：设置本局最大数字，远程初始化对局。

Web 操作对应 API：

- `GET /api/plugin/number_bomb/ui/stats` — 概览统计
- `GET /api/plugin/number_bomb/ui/rooms` — 当前对局状态
- `POST /api/plugin/number_bomb/ui/action` — 操作（init/start/skip/end）
- `POST /api/plugin/number_bomb/ui/init` — 自定义范围初始化
